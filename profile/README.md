# Elio

**Unified AI Command-Line Interface**

Elio is a developer-focused ecosystem that unifies multiple AI providers — Anthropic Claude, Google Gemini, and OpenAI ChatGPT — into a single, consistent terminal interface. Instead of switching between browser tabs and managing multiple accounts, interact with the right AI model for each task directly from the command line.

---

## 🚀 Core Value Propositions

* **Single Login Hub:** Authenticate all providers once using secure OS-level keyring storage.
* **Unified Interface:** Maintain the same commands and workflow regardless of the active AI model.
* **Instant Switching:** Seamlessly jump between models (e.g., Claude for coding, Gemini for research) with a single keystroke.
* **Local Persistence:** All session history and conversation logs are stored locally via SQLite for maximum privacy.
* **Multi-Modal Native:** Attach files and images directly from the terminal.
